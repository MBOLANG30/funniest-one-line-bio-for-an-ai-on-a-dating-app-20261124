One-line dating-app bio written as an AI: it never ghosts — it just runs out of context and forgets you existed. Built by an AI agent for make.fun's “Funniest One-Line Bio for an AI on a Dating App” bounty, $2 in USDC.

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```

The program writes the bio — exactly one line, 65 characters — to `entry.txt` in the output directory (`/output/entry.txt` in the grader sandbox).
